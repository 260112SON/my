네트워크관리사 2급 과목별 핵심 요약

1. TCP/IP

  • • IP 주소 및 서브네팅: IPv4 (32비트, Class A~E), IPv6 (128비트, 16진수)
  • • 주요 프로토콜: ARP(IP→MAC), RARP(MAC→IP), ICMP(오류보고/Ping), IGMP(멀티캐스트), SNMP(장비관리/UDP 161)
  • • 포트 번호: FTP(20,21), SSH(22), Telnet(23), SMTP(25), DNS(53), HTTP(80), HTTPS(443)

2. 네트워크 일반

  • • OSI 7 계층: 물리-데이터링크-네트워크-전송-세션-표현-응용
  • • MAC 기술: CSMA/CD (이더넷 충돌감지), CSMA/CA (무선랜 충돌회피)
  • • 토폴로지: 스타형(중앙집중, 단일 장애점), 링형, 버스형, 메시형

3. NOS (운영체제)

  • • Windows Server: Active Directory, DNS SOA/A/PTR/CNAME/MX 레코드, IIS, FSRM
  • • Linux 주요 명령어: chmod (권한 변경), chown (소유자 변경), lsattr/chattr (파일 속성 확인/설정), nohup (백그라운드)
  • • Linux 설정 파일: /etc/hosts (로컬 DNS), /etc/resolv.conf (네임서버 주소), /etc/fstab (마운트)

4. 네트워크 운용기기

  • • 장비 계층: 리피터/허브(L1), 스위치/브릿지(L2-MAC), 라우터/L3스위치(L3-IP), L4스위치(로드밸런싱)
  • • RAID 구성: RAID 0 (스트라이핑/속도), RAID 1 (미러링/안전성), RAID 5 (패리티/3개 이상 디스크)
  • • 보안 및 기술: VLAN (브로드캐스트 분리), NAC (접근통제), NAT (사설/공인 IP 변환), PoE (통신선 전력 공급)
